\# EmbarkQuiz



\*\*EmbarkQuiz\*\*, also known as \*\*Quiguru\*\*, is a web application for creating and hosting quizzes quickly. Create quizzes by uploading an Excel file or adding questions manually one by one.



It supports both password-protected and open quizzes, live quiz hosting, link sharing, and PDF export containing right/wrong answers with explanations.



EmbarkQuiz is useful for \*\*schools, colleges, and competitive exam coaching centers\*\*.



\## Features



\* Create quizzes by:



&#x20; \* Uploading an Excel file

&#x20; \* Adding questions manually one by one

\* Create password-protected quizzes

\* Create open quizzes without a password

\* Host quizzes live

\* Share quiz links with participants

\* Download a full PDF containing:



&#x20; \* Right and wrong answers

&#x20; \* Answer explanations

\* Suitable for schools, colleges, and competitive exam coaching centers



\## Tech Stack



\* \*\*Next.js\*\* — Web application framework

\* \*\*Firebase\*\* — Authentication, hosting, and backend services

\* \*\*Node.js\*\* — Runtime and supporting server-side functionality



\## Installation



\### 1. Clone the repository



```bash

git clone <repository-url>

cd EmbarkQuiz

```



Replace `<repository-url>` with the URL of this GitHub repository.



\### 2. Install dependencies



```bash

npm install

```



\### 3. Run the development server



```bash

npm run dev

```



The application will be available at:



```text

http://localhost:3000

```



\## Usage



1\. Open the application.

2\. Sign in using your Google account.

3\. Create a new quiz.

4\. Add questions manually or upload an Excel file.

5\. Choose whether the quiz should require a password or remain open.

6\. Host the quiz live or share the quiz link with participants.

7\. After the quiz, download the PDF containing right/wrong answers and explanations.
